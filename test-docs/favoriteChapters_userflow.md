Primary User Flow 1: Empty State & Chapter Discovery

1. Page Entry

Action: The student (Taha) navigates to the Favorite Chapters page by clicking "Favorite Chapters" in the left sidebar.


2. Empty State Verification

Result: The system checks for bookmarked content and renders an empty state screen displaying:



A heart icon graphic.


The message: "No Favorite Chapters Yet".


Instructional text guiding the user on how to add items ("Start adding chapters to your favorites by clicking the favorite button on any lesson page").


3. Redirection to Content

Action: The user clicks the [Browse Chapters] primary button.


Result: The user is redirected to the subject/chapter catalog (or main Dashboard) to explore courses and begin bookmarking content.



Primary User Flow 2: Populated Favorites Management (Target State)

1. Viewing Bookmarks

Action: Once chapters have been favorited on lesson pages, returning to this URL displays a grid or list of saved chapter cards.


Result: The user views key information for each item, such as subject tag, chapter title, and completion status.


2. Direct Lesson Access

Action: The user clicks on a saved chapter card or its corresponding play button.


Result: The user is taken directly to that lesson page to resume study.


3. Unfavoriting Items

Action: The user clicks the favorite/heart icon on an existing card to remove it.


Result: The card is removed from the list in real-time. If all items are removed, the view reverts to the empty state banner.



Alternative Sidebar & Utility Flows

Platform Feedback: Clicking "Feedback" opens a modal or form to submit thoughts on the platform.


External Link: Clicking "Visit Website" directs the user to the public Off The School website.


Dashboard Navigation: Clicking "Dashboard" or "Switch Class" redirects the user back to their active curriculum view.
